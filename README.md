# gtools

This is a collection of tools for working with media.

## Installation

`gtools` is cross platform and can be installed either as a standalone binary or through npm.

> Note: If installed as a package manager, [`vips`](https://www.libvips.org/) will also need to be installed for any commands involving image processing.

### Standalone Binary

```sh
curl -fsSL https://raw.githubusercontent.com/wuguishifu/gtools/main/install.sh | sh
```

### npm Package

```sh
npm i -g @wuguishifu/gtools
```
